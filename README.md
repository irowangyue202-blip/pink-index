# PINK INDEX

イラストの着せ替えと作品アーカイブのWebアプリ。

**公開URL: https://irowangyue202-blip.github.io/pink-index/**

`index.html` の1ファイルだけで動きます（約253KB）。
ダウンロードしてダブルクリックしても同じように動きます。

**イラストは入っていません。** 自分で描いた絵を管理画面（STUDIO）から登録して増やす、
空の器として配っています。

## できること

- **HOME** — 季節ごとに掛け替えるキャンペーン面。**キービジュアルは左右端の矢印／横スワイプ／ドラッグ／絵の左右半分のクリック**で隣の1枚へ切り替わる。枚数・画像・文字・位置・色・並び・自動送りは管理画面から設定できる
- **固定ヘッダー** — 画面幅いっぱいの黒い帯。英字のみで、スクロールしても残る
- **最下部** — 画面幅に迫るロゴ（画像へ差し替え可）と、各画面・TERMS・PRIVACY・CONTACT の横並び
- **DRESS UP** — 素体・髪・表情・衣装・小物・背景を重ねて1着を作る。重ねられない組み合わせは理由を表示して止める
- **CLOSET / GIRLS / COLLECTIONS / GALLERY** — 衣装図鑑・キャラクター図鑑・シリーズ特集・完成作品
- **STUDIO（管理画面）** — 自分で描いた画像の登録・編集・削除
  - HOMEのキービジュアルは、枚数の追加・並べ替え・削除ができます（PC用／スマホ用の画像・文字・リンク・表示位置・トリミング・色を1枚ずつ設定）
  - **HOMEの文字は消せます。** 「文字を出す」を外すと絵だけの面になります（書いた文字は残るので、また出せます）。HOME下部の「もくじ」「点数と更新」も区画ごと消せます
  - **画面を見ながら、つかんで動かせます。** 編集ステージの上で、文字はドラッグで移動・角をひいて幅変更・矢印キーで1%ずつ。「絵を動かす」に切り替えると、絵をつかんで見せる位置を変え、ホイール・2本指・＋−で拡大縮小できます
  - **サイトの文字を1つずつ直せます。**「サイトの文字」では、公開ページを左に出したまま、そのページの文字を書き換え・そろえ（左/中央/右）・非表示にできます
  - 素体（キャラクター本体）も自分で追加できます
  - カテゴリは名前・記号・描画レイヤー（重なり順）・同時に着けられる数を自分で決められます
  - 各アイテムに**フレーバーテキスト**（短いコピー＋本文）を登録できます。管理用のメモとは別項目で、公開/非公開を切り替えられます
  - **公開状態を1点ずつ選べます。** PRIVATE（自分だけ）／PUBLIC（図鑑・ギャラリー）／DRESS-UP（着せ替えで使う）。登録しただけでは公開されません
  - 削除はその場で完全に消えます。組み込みのカテゴリも削除でき、使用中は件数を見せてから素材ごと消します（取り消せるのは「編集をすべて取り消す」のみ）

## 使いはじめ

1. 上の公開URLを開く（または `index.html` をダウンロードしてダブルクリック）
2. STUDIO → 「新規登録」で、素体（キャラクター本体）の絵を1枚登録する
3. 続けて髪・表情・衣装を登録すると、DRESS UP で重ねられるようになる
4. STUDIO → 「HOMEの編集」で、キービジュアルに自分の絵を入れる

登録した素材やコーデは、開いた端末のブラウザの中だけに保存されます（サーバーへは送りません）。
ほかの人にも反映したいときは、管理画面のダッシュボードから `site-data.json` を書き出し、
サイトのソースに置いて作り直してください。

## 注意

- 管理画面（STUDIO）は公開側のヘッダー・フッターからリンクしていません。URLを直接開いて使います。
  この静的版には認証がないため、本番運用では管理者認証つきの別経路へ移す必要があります（`MIGRATION.md`）。
- 保存はブラウザの中だけです。端末を変える・履歴を消すと失われます。
