# PINK INDEX

イラストの着せ替えと作品アーカイブのWebアプリ。

**公開URL: https://irowangyue202-blip.github.io/pink-index/**

`index.html` の1ファイルだけで動きます（約240KB）。
ダウンロードしてダブルクリックしても同じように動きます。

**イラストは入っていません。** 自分で描いた絵を管理画面（STUDIO）から登録して増やす、
空の器として配っています。

## できること

- **HOME** — 季節ごとに掛け替えるキャンペーン面。**横スクロールで切り替わるキービジュアル**から始まり、
  構図を変えながらビジュアルが縦に続く。枚数・画像・文字・色・並びは管理画面から差し替え可能
- **DRESS UP** — 素体・髪・表情・衣装・小物・背景を重ねて1着を作る。重ねられない組み合わせは理由を表示して止める
- **CLOSET / GIRLS / COLLECTIONS / GALLERY** — 衣装図鑑・キャラクター図鑑・シリーズ特集・完成作品
- **STUDIO（管理画面）** — 自分で描いた画像の登録・編集・削除
  - HOMEのキービジュアルは、枚数の追加・並べ替え・削除ができます（PC用／スマホ用の画像・文字・リンク・表示位置・トリミング・色を1枚ずつ設定）
  - 素体（キャラクター本体）も自分で追加できます
  - カテゴリは名前・記号・描画レイヤー（重なり順）・同時に着けられる数を自分で決められます
  - 各アイテムに**フレーバーテキスト**（短いコピー＋本文）を登録できます。管理用のメモとは別項目で、公開/非公開を切り替えられます
  - 削除はその場で完全に消えます（取り消せるのは「編集をすべて取り消す」のみ）
- **DESIGN SYSTEM** — 色・文字・部品・モーションの定義

## 使いはじめ

1. 上の公開URLを開く（または `index.html` をダウンロードしてダブルクリック）
2. STUDIO → 「新規登録」で、素体（キャラクター本体）の絵を1枚登録する
3. 続けて髪・表情・衣装を登録すると、DRESS UP で重ねられるようになる
4. STUDIO → 「HOMEの編集」で、キービジュアルに自分の絵を入れる

登録した素材やコーデは、開いた端末のブラウザの中だけに保存されます（サーバーへは送りません）。
ほかの人にも反映したいときは、管理画面のダッシュボードから `site-data.json` を書き出し、
サイトのソースに置いて作り直してください。

## 注意
