# PINK INDEX

イラストレーションのポートフォリオサイト。

**公開URL: https://irowangyue202-blip.github.io/pink-index/**

`index.html` の1ファイルだけで動きます（約185KB）。
ダウンロードしてダブルクリックしても同じように動きます。

**イラストは入っていません。** 自分で描いた絵を管理画面（STUDIO）から登録して増やす、
空の器として配っています。

## 画面

- **HOME** — キービジュアル（1枚ずつ、左右の矢印・スワイプ・ドラッグ・絵の左右半分のクリックで切り替え）から始まり、
  FEATURE / DETAILS / COLOR STORY / NEW / SPOTLIGHT / ARCHIVE / ABOUT と、見せ方の違う区画が続きます。
  作品が足りない区画は出ません
- **WORKS** — 全作品の一覧。分類・タグ・検索はページの中で絞り込みます
- **SERIES** — 世界観やテーマでまとめた作品群
- **ABOUT / CONTACT** — 作者と連絡先
- 最下部に大きなロゴと、TERMS / PRIVACY を含む横並びのリンク

ヘッダーは画面先頭では透明で、下へスクロールすると隠れ、上へ戻すと乳白色のぼかしで戻ります。
文字色（黒／白）は作品ごとに選べます。

## STUDIO（管理画面）

上のURLに `#/studio/` を付けて開きます（公開画面からはリンクしていません）。

- 作品の追加・編集・削除。公開状態は **DRAFT / PRIVATE / PUBLIC** から選び、**登録しただけでは公開されません**
- 画像の説明（代替テキスト）は必須です
- シリーズと分類の追加・削除。使用中のものは件数を見せてから、紐付けを外す／別の分類へ移します
- HOMEの区画の並べ替え・公開/非公開・追加・削除。キービジュアルは枚数・画像（PC/スマホ別）・文字・
  文字色・見せる位置・拡大縮小を1枚ずつ設定できます
- **画面を見ながら、つかんで動かせます。** 文字はドラッグで移動・角をひいて幅変更、
  「絵を動かす」に切り替えると絵をつかんで位置を変え、ホイール・2本指・＋−で拡大縮小
- **サイトの文字**を1つずつ書き換え・そろえ・非表示にできます
- 最下部の大きなロゴを画像に差し替えられます

## 使いはじめ

1. 上の公開URLを開く（または `index.html` をダウンロードしてダブルクリック）
2. `#/studio/new/` で作品を1点登録する（画像・作品名・画像の説明）
3. 公開状態を PUBLIC にすると WORKS に出る
4. `#/studio/home/` でキービジュアルに絵を入れる

登録した内容は、開いた端末のブラウザの中だけに保存されます（サーバーへは送りません）。
ほかの人にも反映したいときは、ダッシュボードから `site-data.json` を書き出し、
サイトのソースに置いて作り直してください。

## 注意

- 管理画面には認証がありません。本番運用では管理者認証つきの別経路へ移す必要があります。
- 保存はブラウザの中だけです。端末を変える・履歴を消すと失われます。
- 広告は掲載していません。
